Learner

A learner's job is to tally Accepted messages and record a value once quorum is reached.

{% raw %} 

pub struct Learner {
    id: i32,
    quorum_number: i32,
    votes: HashMap>
}
{% endraw %}

Learners track votes for each ballot. To know it has met quorum, it must compare the votes for a value. Since messages can arrive asynchronously, this naive implementation tracks all received messages because they can come out of order. As soon as any ballot meets quorum, the learner can infer, from the protocol constraints, that any future ballot will contain the same value. This enforces consistency and validity.

It can receive one message:

Accepted

{% raw %} 

Accepted {
    from: NodeId,
    ballot: Ballot,
    value: PaxosCommand,
}
{% endraw %}

Accepted is sent to all learners or a distinguished learner, where it tallies Accepted messages to ensure quorum is reached.
