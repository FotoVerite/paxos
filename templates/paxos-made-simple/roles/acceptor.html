Acceptor

An acceptor's job is to keep track of the last value it voted for and its latest ballot number it has promised to accept.

{% raw %} 

pub struct Acceptor {
    id: i32,
    next_ballot: Option,
    previous_vote: Option<(Ballot, Value)>
}
{% endraw %}

Acceptors are a simple filter; they have no other job besides being non-volatile memory.

It can send two messages and receive two messages:

Prepare

{% raw %} 

Prepare { from: NodeId, ballot: Ballot }
{% endraw %}

When Prepare is received, it will respond with an accept message. If the sent ballot is larger than next_ballot, it will set next_ballot to that ballot.

Promise

{% raw %} 

Promise { from: NodeId, ballot: Ballot, last_voted: Option<(Ballot, Value)> }
{% endraw %}

Promise also enforces the nontriviality and consistency of the ballot. The acceptor sends back information on what it last voted for, if any. From this, the proposer can determine if its current ballot is greater than any seen before.

Accept

{% raw %} 

Accept {
    from: NodeId,
    ballot: Ballot,
    value: PaxosCommand,
}
{% endraw %}

Accept is sent to acceptors to ask if their promise is still valid. If so, they reply with Accepted to one or more learners depending on the implementation.

Accepted

{% raw %} 

Accepted {
    from: NodeId,
    ballot: Ballot,
    value: PaxosCommand,
}
{% endraw %}

Accepted is sent to all learners or a distinguished learner, where it tallies Accepted messages to make sure quorum is reached.
