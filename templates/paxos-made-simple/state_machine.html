Implementing a State Machine

Replicated State Machines

Multiple machines execute the same sequence of commands and maintain identical state. Paxos ensures all replicas agree on the log of commands.

How It Works

  1. Client sends command to replica
  2. Replicas use consensus to agree on appending the command
  3. All replicas execute the command
  4. All produce the same result
