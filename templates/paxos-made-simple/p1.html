P1

Definition
In the absence of failure or message loss, we want a value to be chosen even if only one value is proposed by a single proposer. This suggests the requirement:
P1. An acceptor must accept the first proposal that it receives
LAMPORT, P. 2 — §2.2

Here he is stating that an acceptor is a filter. It accepts it doesn't decide, it just enforces. This he later refines to.

Refinement
What about an acceptor? It can receive two kinds of requests from proposers: prepare requests and accept requests. An acceptor can ignore any request without compromising safety. So, we need to say only when it is allowed to respond to a request. It can always respond to a prepare request. It can respond to an accept request, accepting the proposal, iff it has not promised not to. In other words: subsumes P1.
P1a. An acceptor can accept a proposal numbered n iff it has not responded to a prepare request having a number greater than n.
Observe that P1a subsumes P1
LAMPORT, P. 5 — §2.2

For an acceptor it must accept all values it receives that are greater than or equal to promised proposals. Lamport here is stating in plain text what quorum/consistency from Theorem One of Part Time Parliament is providing. That if proposals of only greater numbers are accepted quorum is kept. Based on P2 consistency and safety will be assured if proposers logic is sound.
