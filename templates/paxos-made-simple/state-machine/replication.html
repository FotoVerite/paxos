Replicated State Machines

The Core Concept
To guarantee that all servers execute the same sequence of state machine commands, we implement a sequence of separate instances of the Paxos consensus algorithm, the value chosen by the i th instance being the i th state machine command in the sequence. Each server plays all the roles (proposer, acceptor, and learner) in each instance of the algorithm.
LAMPORT, P. 8 — §3

Instead of relying on a single central server (which fails catastrophically), we replicate the state machine across multiple servers. Because state machines are deterministic, all replicas produce identical results when executing the same sequence of commands.
