Ballots & Acceptors

Let's get into the details. Ballots and acceptors are the machinery that makes Synod work.

What is a ballot?

A ballot is just a number. Actually, a pair: a round number and a leader ID. Ballots have a natural ordering: ballot (0, leader0) comes before ballot (0, leader1), which comes before ballot (1, leader0), and so on.

Each ballot has a designated leader—the node that will try to get values chosen in that ballot. Different ballots have different leaders.

Ballots exist only in the minds of nodes running Paxos. They're not created; they just are. Whenever a node wants to be a leader, it picks a ballot number and claims that ballot.

Acceptor state

An acceptor maintains a few pieces of state:

  • ballot_accepted: The highest ballot this acceptor has adopted.
  • pvalues: A set of (ballot, slot, value) tuples representing values the acceptor has accepted.

That's it. Simple. But these simple rules maintain safety.

Scout messages (Phase 1a, 1b)

The scout in a leader sends a message: "Adopt ballot B."

An acceptor receives this. It checks: is B higher than my ballot_accepted? If yes, update ballot_accepted to B and respond with the pvalues I've accepted so far. If no, reject.

The leader needs a majority of acceptors to respond positively. If it gets them, the leader knows: "I'm the highest ballot these acceptors have seen. I know which values they've already accepted."

Commander messages (Phase 2a, 2b)

Once the leader has a majority, it sends: "Accept value V for slot S in ballot B."

An acceptor checks: is B the same as my ballot_accepted? If yes, accept (record the pvalue). If B is lower, reject. If B is higher than ballot_accepted, reject (the acceptor should have received a scout message first).

Once a majority accepts, the value is chosen. The leader learns this and broadcasts it.

Why this guarantees safety

Here's the key: acceptors only accept values in ballots they've adopted. And they only adopt ballots in increasing order. This means if value V is chosen in ballot B for slot S, no other value can be chosen for slot S in any ballot higher than B (because the higher ballot's leader learned about V from the acceptors during the scout phase).

This is safety: one and only one value per slot.
