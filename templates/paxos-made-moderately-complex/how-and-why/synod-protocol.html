The Synod Protocol

The Synod protocol is the consensus mechanism. It solves this problem: given a set of proposed values (commands from replicas), choose one value such that all acceptors (nodes participating in consensus) agree.

The protocol has two phases. We'll see why you need both.

Phase 1: Scout (Prepare)

A leader starts by running a scout. The scout talks to acceptors with a ballot number. The scout asks: "Will you adopt this ballot?"

Acceptors have rules: they will only adopt a ballot if it's higher than any ballot they've seen before. Once they adopt a ballot, they commit to not adopting any lower ballot.

If the scout gets a majority of acceptors to adopt the ballot, the scout reports back: "You're the leader for this ballot." The leader can now propose values.

Phase 2: Commander (Accept)

Once the leader has a majority adopting its ballot, it can propose a value for a slot. The leader sends a message to acceptors saying: "Accept this value for this slot in this ballot."

Acceptors accept the value if they haven't adopted a higher ballot. Once a majority accepts, the value is chosen.

This is safety: the acceptor rules ensure that if a value is chosen, no other value will ever be chosen for that slot.

Why two phases?

Phase 1 ensures the leader knows which values might have already been chosen. This is crucial. If a leader crashes and a new leader takes over, the new leader has to respect decisions made by the old leader.

Phase 2 is where the actual proposal happens. The two phases together guarantee that all replicas agree on the final value.

Acceptors remember

Acceptors are dumb compared to leaders. They just follow rules:

  • Store the highest ballot number you've adopted.
  • Store the value you've accepted for each slot in each ballot.
  • Don't adopt a lower ballot than the highest one you've seen.
  • Don't accept a value in a ballot lower than the highest ballot you've adopted.

By following these rules, acceptors maintain the invariants that guarantee safety. The leader is smart (it runs Synod), but the acceptors are the ones who ensure consistency.
