When Paxos Works

The previous section explained how Paxos guarantees safety—all nodes agree on command ordering. But there's a catch: the basic protocol doesn't guarantee liveness.

It's possible to construct a scenario where two leaders keep proposing different values, each preempting the other, in an endless loop. Neither leader succeeds. Clients never get responses. The system is safe but stuck.

This section is about fixing that problem. The solution is elegant: weak leader election and timeouts.
