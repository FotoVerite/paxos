Replica Execution Model

Crash Failure
In order to tolerate f crashes, Paxos needs at least f + 1 replicas to maintain copies of the application state.Replicas are the core building blocks of the replicated state machine (RSM), while all other components exist to ensure consensus between them.
RENESSE, P. 3 §2

For every failure one wants the system to tolerate you must have at least f + 1 replicas holding the application state. So if you want to survive five unavailable replicas one would need a minimum of six replicas

Messages
When a client κ wants to execute a command (κ, cid, op), its stub routine broadcasts a (request, (κ, cid, op)) message to all replicas and waits for a (response, cid, result) message from one of the replicas.
RENESSE, P. 3 §2

Commands on the client are broadcast in a request message of (k, cid, op) to all replicas and waits for a response message from one replica of type (response, cid, result). How replicas coordinate to determine which replica responds is deferred to later sections.

Slots
The replicas can be thought of as having a sequence of slots that need to be filled with commands. Each slot is indexed by a slot number. A replica, on receipt of a (request, c) message, proposes command c for its lowest unused slot. We call the pair (s, c) a proposal for slot s. In the face of concurrently operating clients, different replicas may end up proposing different commands for the same slot. In order to avoid inconsistency, a replica awaits a decision for a slot before actually updating its state and computing a response to send back to the client.
Replicas are not necessarily identical at any time. However, replicas apply operations to the application state in the same order.
RENESSE, P. 3 §2

The slots are similar to Lamport's Ledger. Each slot contains one command and are applied in order. Commands are proposed for slots and become fixed once a proposal is chosen by the Paxos protocol. Because the environment is asynchronous it cannot be assumed that all replicas are identical at any one moment; but that they will all have same state at given slot index once applied.
