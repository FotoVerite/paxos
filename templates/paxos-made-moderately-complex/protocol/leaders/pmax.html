$pmax(pval)$

Definition

After the leader receives adopted, along with ballot_num and pvals, it determines, for each slot, the command corresponding to the maximum ballot number in pvals by invoking the function pmax. Formally, the function pmax(pvals) is defined as follows:

$$ \text{pmax}(pvals) \equiv \{(s, c) \mid \exists b : (b, s, c) \in pvals \wedge \forall b', c' : (b', s, c') \in pvals \Rightarrow b' \le b \} $$

The update operator $\triangleleft$ applies to two sets of proposals. $x \; \triangleleft \; y$ returns the elements of $y$ as well as the elements of $x$ that are not in $y$. Formally:

$$ x \; \triangleleft \; y \equiv \{(s, c) \mid (s, c) \in y \; \lor \; ((s, c \in x \wedge \nexists c' : (s, c') \in y))\} $$

Thus, the line:

proposals := proposals ◀ pmax(pvals);

updates the set of proposals, replacing for each slot number the command corresponding to the maximum pvalue in pvals, if any. Now the leader can start commanders for each slot while satisfying Invariant C2.

RENESSE, P. 9 §2 - Scouts, Passive and Active Modes

When a Leader receives the adopted message from a scout, it ascertains from the included pval set through the pmax function commands for each slot in contention.

The pmax function is defined as: for each slot-command pair, there exists a ballot number in the tuple (Ballot, Slot, Command) in pvals that is greater than or equal to any other ballot number for that slot.

When updating the internal set of proposals, one cannot simply take the output of pmax, because some previous proposals might be lost. One must take the union of all previous pvalues that are not included in the pvals set sent by the scout for each slot, which is exactly what the $\triangleleft$ operator accomplishes.
