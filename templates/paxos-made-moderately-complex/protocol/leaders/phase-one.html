Leader Modes - Phase One

Null Pvals Set

Case One
If, for some slot $s$, there is no pvalue in $pvals$, then prior to $ballot\_num$ it is not possible that any pvalue has been chosen or will be chosen for slot $s$.
After all, suppose that some $pvalue\ \langle b, s, c \rangle$ were chosen, with $b < ballot\_num$. This would require a majority of acceptors $\mathcal{A_0}$ to accept $\langle b, s, c \rangle$. But we have responses from a majority $\mathcal{A}$ that have adopted $ballot\_num$ and have not accepted, nor can accept, pvalues with ballot number smaller than $ballot\_num$ (Invariants $A1$ and $A2$). $$ \mathcal{A} \cap \mathcal{A_0} \neq \varnothing $$
so some acceptor in the intersection must have violated Invariant $A1$, $A2$, or $A3$, which we know cannot happen.
Therefore, because no pvalue has been or will be chosen for slot $s$ prior to $ballot\_num$, the leader may propose any command for that slot without conflicting with an earlier ballot, thereby enforcing Invariant $C2$.
RENESSE, P. 8 §2 - Scouts, Passive and Active Modes

Given Invariant A1, A2, A3; Ballot Ordering, Ballot Consistency, and Append Only. It can be proven logically that if there are no pvalues for slot $s$ among a quorum $\mathcal{A}$ of acceptors. Hence the leader can propose any value for any slot that falls into case one without violating Invariant $C2$.

At least One Pvalue

Case Two
Otherwise, let $pvalue\ \langle b, s, c \rangle$ be the pvalue with the maximum ballot number for slot $s$. Because of Invariant $A4$, this pvalue is unique—there cannot be two different commands for the same ballot number and slot number.
Also note that $b < ballot\_num$ (because acceptors only report pvalues they accepted before $ballot\_num$).
Like the leader of $ballot\_num$, the leader of $b$ must have picked $c$ carefully to ensure that Invariant $C2$ holds. Thus, if a pvalue is chosen before or at $b$, the command it contains must be $c$.
Since all acceptors in $\mathcal{A}$ have adopted $ballot\_num$, no pvalues with ballot numbers between $b$ and $ballot\_num$ can be chosen (Invariants $A1$ and $A2$).
Therefore, by using $c$ as the command for slot $s$, $\lambda$ enforces Invariant $C2$.
RENESSE, P. 9 §2 - Scouts, Passive and Active Modes

Given Invariant A4; Command Identity It can be proven logically that any pvalue a quorum $\mathcal{A}$ of acceptors must have been chosen by A1-A5 invariants. While there are reasons any two individual pvalues equal each other, by A4 and quorum intersection any chosen pvalue would have been the maximum pvalue of the set and the Leader can safely pick that as it's value and enforce C2 itself. The commander will then send this picked command to all acceptors to be accepted and then learned by the replicas.
