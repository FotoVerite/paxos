Commander Execution Model

Commander Thread
According to Invariant A4, there can be at most one proposed command per ballot number and slot number. The leader of a ballot is responsible for selecting a command for each slot, in such a way that selected commands cannot conflict with decisions on other ballots (Invariant A5). A leader may work on multiple slots at the same time. When, in ballot b, its leader tries to get a command c for slot number s chosen, it spawns a local commander thread for (b, s, c).
RENESSE, P. 6 §2 - Leaders and Commanders

Commanders are threads spawned by a leader to decide the value of a command for a given slot. A leader can run multiple commanders concurrently, one per (ballot, slot). Each commander must ensure that its proposed value respects Invariant A5.
