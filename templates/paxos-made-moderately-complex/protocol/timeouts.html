Timeouts

Timeouts

These assumptions can be exploited as follows: we use a scheme similar to the one described above, based on pinging and timeouts, but the value of the timeout interval depends on the ballot number: the higher the competing ballot number, the longer a leader waits before trying to preempt it with a higher ballot number. Eventually, the timeouts grow large enough that some correct leader can always complete a ballot and get its proposals chosen.

RENESSE, P. 11 §3 - When Paxos Works

A solution using the given bounds works like this. Since we cannot assume how long message can take in a system we need the system itself to regulate the timeout. One starts with a relatively short timeout say 50 micro seconds. Each time a ballot is incremented that timeout will be extended. Eventually the system will reach an equilibrium where timeouts are larger then most delayed pings.

Backoff

For good performance, one would like the timeout period to be long enough so that a leader can be successful, but short enough so that the ballots of a faulty leader are preempted as quickly as possible. This can be achieved with a TCP-like AIMD (Additive Increase, Multiplicative Decrease) approach for choosing timeouts. The leader associates an initial timeout with each ballot. If a ballot gets preempted, the next ballot uses a timeout that is multiplied by some small factor larger than one. With each chosen proposal, this initial timeout is decreased linearly. Eventually the timeout will become too short, and the ballot replaced with another even if its leader is non-faulty, but this does not affect correctness.

RENESSE, P. 11 §3 - When Paxos Works

Since faults are a certainty, hence ballot timeouts will grow very large given enough time, we need a way to safely decrees them. This is what AIMD gives us. Take a timeout of 500 milliseconds, for ever successful proposal we can take off one microsecond. Eventually the timeout will be so small it will cause a leadership change, but that is not an issue for safety or liveness. In fact some rotation of leadership can be healthy for the system given implementation. Periodic leadership changes can help reduce hot-spots and contention in the system.

This is usually called leadership election. But Renesse is at pains to call out that there is no election, a ballot is simply owned by a leader.
