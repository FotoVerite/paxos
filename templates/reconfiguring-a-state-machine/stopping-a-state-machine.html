Stopping a State Machine

Stop Command Concept

The paper introduces mechanisms to stop advancing one configuration's command stream so a successor can safely take over.

Stop Sign, Padding, Brick Wall

These techniques handle boundary conditions: where to terminate, how to fill uncertain tail slots, and how to prevent old configuration progress from crossing a safety boundary.

System Mapping

In our implementation, this likely corresponds to explicit stop markers in the replicated log and strict replica/leader checks against the latest effective configuration epoch.
