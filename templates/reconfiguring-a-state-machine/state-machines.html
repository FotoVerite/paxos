State Machines

Commands and Histories

Replicated state machines execute an ordered sequence of commands. Reconfiguration must preserve this single logical sequence even while the executor set changes.

Preliminaries

A configuration defines which processes participate and how consensus is run for a command range. The tricky part is handing off from one configuration to the next without ambiguity.

Garbage Collection

Membership changes add metadata and historical dependencies. Practical systems need explicit pruning rules so obsolete config state can be removed after it is no longer needed for safety.
