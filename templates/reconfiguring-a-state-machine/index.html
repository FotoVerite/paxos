Reconfiguring a State Machine

This section is a rough, implementation-oriented walkthrough of Lamport, Malkhi, and Zhou's tutorial on configuration changes for replicated state machines.

Source paper: Reconfiguring a State Machine ↗

Why This Matters

Paxos tutorials usually assume a fixed set of participants. Real systems need to add, remove, and replace nodes without breaking safety or freezing availability.

How This Track Is Organized

This rough pass mirrors the paper's flow so we can iterate toward code:

  • State machines and command logs
  • A simple reconfiguration mechanism
  • Correctness intuition
  • Harder cases and edge handling
  • Operational interface for real systems
