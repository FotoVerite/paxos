Policy vs Safety

Safety rules define what transitions are legal; policy decides when to trigger them. Keep these concerns separate so operator logic cannot violate protocol invariants.

Input Signals

Typical drivers include failures, planned maintenance, load distribution, and capacity growth.

For This Project
