Section 2. Lemma

Lemma:

If $\mathbf{B1}(\mathcal{B})$, $\mathbf{B2}(\mathcal{B})$, and $\mathbf{B3}(\mathcal{B})$ hold, then for any $B, B' \in \mathcal{B}$:

$\big((B_{\text{qrm}} \subseteq B'_{\text{vot}}) \wedge (B'_{\text{bal}} > B_{\text{bal}})\big) \Rightarrow (B'_{\text{dec}} = B_{\text{dec}})$

That is, if a quorum of votes for $B$ is included in the votes of $B'$ and $B'$ has a higher ballot number, then the decree chosen by $B'$ must be the same as the decree of $B$.

Lamport does this by contradiction. Which I will now try do in plain english.

  1. Let's Assume a counterexample exists: There’s a valid ballot C which comes after a valid ballot with a different decree. Let Ψ(B, B) be the set of all such later ballots.
  2. Given Constraint B2 Ballot C quorum includes the quorum of Ballot B and will be able to use MaxVote to find said vote
  3. Apply MaxVote: MaxVote(C_bal, C_qrm, B) selects the largest prior vote in C’s quorum. By B3, C must adopt the decree of that vote.
  4. Observe the conflict: The vote chosen by MaxVote is either in B’s votes (so it has decree B_dec) or is null. Either way, C cannot legitimately choose a different decree than B.
  5. Contradiction arises: Our assumption that C picks a different decree is impossible, because the rules force it to pick B’s decree. Ψ(B, B) can only be empty.
