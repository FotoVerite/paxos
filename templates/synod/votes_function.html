$\text{Votes}(\mathcal{B})$ Function

For any votes $v$ and $v'$ , if $v$bal < $v'$ bal then $\lt$ $v'$

This simple state that for any two unique votes, if the ballot id of one is less than the other then it is less than the other then the vote is less then that other one. This is just a formal way of saying that votes can be ordered by their ballot id

For any set $\mathcal{B}$ of ballots, the set $\text{Votes}(\mathcal{B})$ of votes in $\mathcal{B}$ was defined to consist of all votes $\text{v}$ such that $\text{v}$pst $\in$ $\text{b}$vot, $\text{v}$bal = $B$bal , and $v$dec = $B$dec for some $B$ $\in$ $B$.

$\text{Votes}(\mathcal{B})$ is a name for a set, parameterized by a set of ballots. Given a group of ballots, it refers to all votes that match any of them. It outputs the set of votes for a ballot that were cast by the priest that were of the ballot vote where the vote ballot id = the round/ballot ballot id and the vote decree is equal to the ballot decree

Notice that this means that a vote itself contains it's own decree and ballot_id at least as a inditification and or as meta data

A formal definition might read.
A vote $v$ belongs to $\mathrm{Votes}(\mathcal{B})$ exactly when all of the following hold for some $B \in \mathcal{B}$:

  1. $v.\mathrm{pst} \in B.\mathrm{vot}$
  2. $v.\mathrm{bal} = B.\mathrm{bal}$
  3. $v.\mathrm{dec} = B.\mathrm{dec}$
