Vertical Paxos

This track is for the version of Paxos where membership changes are built into the model instead of being bolted on afterward.

The short version is that ordinary Paxos explains how one configuration behaves. Vertical Paxos is about how configurations hand work to each other without losing the plot.

What This Track Is For

To explain why configuration management becomes its own protocol problem once the system needs to keep running while the cast changes.

What Makes It Different

The point here is not just ballots and quorums. It is who gets to define the active configuration, who carries state forward, and how one era hands off to the next.

Starting Point

This is just the opening shell for now. The next passes can add the actual paper walk, demos, and the more careful treatment of the master and configuration handoff.
