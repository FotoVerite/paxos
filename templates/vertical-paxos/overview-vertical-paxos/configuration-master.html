Vertical Paxos Overview - ACM

While it's possible to design a system that can reconfigure itself, in practice it is often cleaner to have configuration controlled by a separate process outside of the Paxos instance. This Auxiliary Configuration Master determines the set of acceptors and selects a leader for each configuration, rather than relying on the system to converge on leadership through ballots.

This is a marked difference from earlier Paxos formulations, where leadership emerges from within the protocol itself. Here, leadership and configuration are assigned externally.

This change of centralization allows more robust tolerance of failures. Since arbitrary overlap of quorum is no longer a requirement.

Because the master is only involved during reconfiguration—which is relatively infrequent—it can be implemented as a highly reliable component without becoming a performance bottleneck.
