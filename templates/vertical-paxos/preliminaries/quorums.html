Preliminaries - Quorum

In practice, RQuorums(b) is a function tracking the active acceptors in the read quorum and WQuorums(b) the active acceptors in the write quorum. Such acceptors should follow the formula below to assure the invariant as laid out above.

w + r > N
w = write set r = read set N = total set

The authors here are repeating what has already been setup in the premise. In Vertical paxos the ACM computes the r and w quorums in reaction to the system. In Vertical Paxos II the ACM can delay configuration till it is valid and remove Ballots where configuration failed. The whole oracle move is fucking nonsense. The point is just that the proof should hold for whatever valid ballot and quorum choices the master ends up making. So instead of modeling those decisions as they happen, The authors freeze them up front and calls it an oracle. Mathematically fine. Explanatorily terrible.
