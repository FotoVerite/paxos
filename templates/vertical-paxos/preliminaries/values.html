Preliminaries - Values

A value is chosen when a majority of the current write quorum votes in a ballot.

Read and write quorums must overlap, so any value that could have been chosen in a previous ballot cannot be ignored by a new one.

If a read quorum reports that all of its acceptors have moved to ballots higher than b and none of them voted in b, then no value could have been chosen in ballot b.
